# 当年政策核验

这是一套使用 Skill 时执行的流程，不是已经完成的全国政策更新。本次转换未建立2026或2027年院校政策数据库。

## 把问题拆成最小事实

先写明报考年份、省份、考生类别、院校、专业或项目、当前状态。例如“某年河北普通高中毕业生，能否以某项目参加某校招生”，不能只查“这个学校能不能报”。

每条资格要求、收费、日期和录取后果分别填写政策证据表。对尚未发布的目标年规则，保留“未发布/待核验”，上一年资料仅作准备线索。

## 到哪里查

| 问题 | 优先查阅的官方材料 |
|---|---|
| 全国政策、特殊类型招生 | 教育部当年招生文件、阳光高考公开信息 |
| 本省资格、实施地区、投档和志愿 | 本省教育考试院或招生考试机构年度文件 |
| 某校选科、费用、计划、培养和测试 | 学校本科招生官网当年章程、项目简章、分省计划、补充通知 |
| 公费、定向及就业义务 | 有关教育、卫生、农业等主管部门文件及实际签署的培养就业协议 |
| 招飞、军校、军士 | 相关军队招生单位、招飞机构、省级招生通知；民航查相关官方招飞通知 |
| 公安资格与毕业招录 | 公安主管部门、招考主管部门、院校对应招生与招录文件 |
| 体育项目 | 教育部、国家体育总局及相关官方招生平台年度文件、院校简章 |
| 合作办学与境外学历 | 教育主管部门审批信息、合作双方官网、相关学历认证官方说明 |

首次使用网络时从机构真实官网检索页面，不猜报名网址。只读即可完成核验；登录、报名、付款与提交属于后续独立动作。

## 核验顺序

1. 匹配年份和适用范围；发布较新不一定适用于所问年份。
2. 检查正文、附件及后续更正，保留文件标题、发布机构、发布日、网址、查阅日和条款定位。
3. 区分必要条件和充分条件。资格合格不代表入围，入围不代表录取，录取不代表毕业后一定录用。
4. 先判硬条件，再看计划与排序。没有官方计划、同口径位次或学校具体规则，不估录取概率。
5. 遇到上位文件、地方实施与高校细则不一致，先检查是否存在适用范围或时间差；无法解释时记录冲突，指向招生部门核实，不擅自择一。
6. 按证据修订路径状态，写出本次建议与书中版本的差异。

## 数值与日期

同一省份、年份、科类或选科组合、招生项目和分数口径才有比较基础。跨年尽量使用匹配制度的位次及计划变化，并说明其局限；不能仅凭往年最低分推算稳录取。

综合分计算之前确认原始满分、折算顺序、权重、舍入规则、单项最低线、志愿排序与同分规则。任何一项未知，停止精确计算并列为待补项。

所有行动日期标注所属招生年。把书中“3月至4月”直接改成今年具体报名截止日是不允许的。尚未发布通知时可制定准备清单，但不制造截止日。

## 无法联网时

仍可交付书中路径原理、适配问题、比较维度、材料准备和官方待查项。开头说明“以下是基于2024年版的路径讨论，当前资格与时间尚未核验”，不要用已过时的精确数值填空。
