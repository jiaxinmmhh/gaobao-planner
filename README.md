# 高报规划 Skill

基于张雪峰·峰阅教研团队《高中生多元升学规划》（2024年4月版），用于学生画像、多元升学路径筛选、项目比较与报考准备。

发布版本：`1.0.0`。这是独立整理的学习与咨询辅助工具，与原书作者、编著团队及出版社无隶属或背书关系。

## 使用

在支持本地 Skills 的工具中，将整个 `gaobao-planner` 目录放入技能目录。Codex 可放到 `~/.codex/skills/gaobao-planner/`；保留 chapters、references、templates、scripts 等全部文件。已安装但当前会话未显示时，在新会话使用。

直接说：“用高报规划（gaobao-planner），先了解学生条件，再筛选升学路径。”

示例：“用高报规划，比较强基和综合评价。”或“用高报规划，帮我核查河北学生的三大专项条件。”

在 Skill 目录内可运行：

```sh
python3 scripts/search.py '公费师范'
python3 scripts/search.py --chapter 8
python3 scripts/search.py '招生来源' --json
python3 scripts/read_source.py --epub '/你的原书路径.epub' --section s001
```

两个脚本只依赖Python 3标准库。检索不需要原书；回读原书需要用户持有的EPUB。`read_source.py --section`接受索引ID或索引中的XHTML路径；带`--max-chars`控制读取量，输出会提示是否截断。

## 文件

22个按需加载章节；术语表、方法库、决策速查；187项目录索引与图片来源索引；6个附录导航；学生画像、项目比较、政策证据、行动与咨询模板；检索和原书回读脚本；8个使用演练。

## 使用边界

这是书籍方法与咨询流程 Skill，不是当前招生数据库。具体院校、分数、位次、费用、日期、资格、编制与录取后果需要目标年官方材料。本书没有完整普通批志愿数据，艺术等未覆盖路线需要补充资料。

包内不附原EPUB、全书抽取文本和原图。来源、提取覆盖、旧政策与内部疑点均在 references 中记录。

本仓库发布通用方法、模板、脚本与假设演练，不包含真实学生档案或咨询聊天记录。原书名称和作者用于来源说明；原书权利归相应权利人所有。
